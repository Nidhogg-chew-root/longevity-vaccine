# Engineering notes

Working notes written while the mod was built: the lesson behind each rule and the
history of each screen. Each is dated by its content and may describe a state the code
has since moved past; where a note and the code disagree, the code and its tests are
right. They are published as written, apart from the removal of remarks about the
maintainer's own machine and working process. Most paths they cite under `work\briefs`,
`work\_*`, `refs\` and "the maintainer's work log" are private working files that are
not part of this repository.

A `[[name]]` link anywhere in this repository (code comments, `docs/skills/`,
`work/WHY.md`, these notes) is the note `docs/notes/name.md`; an underscore in a link
is read as a hyphen. The links `[[frida-tracing]]`, `[[input-clicks]]`, `[[prefwin-settings]]`, `[[scaling-frames]]`, `[[scaling-layout]]`, `[[scaling-sprites]]`, `[[scaling-text]]`
are the skills in `docs/skills/`. "(a private note)" marks a link to a note that is
not part of the source release: notes about publishing, hosting and the maintainer's
own setup stay private.

Addresses are for the PRACX-patched GOG binary the mod targets. `g` is the runtime
scale (16 = the native 1024x768 layout); `s(v)` is `floor(v*g/16)`.
